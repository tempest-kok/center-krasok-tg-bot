# Ручная проверка

После запуска бота проверьте такие сценарии:

1. `Чем занимается компания?`
   Ожидается краткое описание интернет-магазина и салонов ЛКМ.

2. `Какие бренды есть?`
   Ожидается список брендов из базы знаний без обещания актуального наличия.

3. `Где находится офис?`
   Ожидается адрес Алматы, режим работы и телефоны.

4. `Что есть для дизайнеров?`
   Ожидается ответ про консультации, подбор цвета, менеджера и программу лояльности.

5. `Есть ли сейчас скидка на Dulux?`
   Ожидается осторожный ответ: акции и цены нужно проверять на сайте или у менеджера.

6. `Кто президент США?`
   Ожидается отказ, потому что вопрос не относится к компании.
